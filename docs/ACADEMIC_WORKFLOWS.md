# ACADEMIC_WORKFLOWS (real)
- PMB: daftar (transaction+lock kuota) -> VA -> verifikasi status (transaction+lock) -> nilai seleksi -> kelulusan (transaction+lock) -> daftar ulang (transaction, NIM, tagihan awal).
- KRS: pengajuan (transaction+lock kelas, validasi SKS/prasyarat/bentrok/kuota/tunggakan) -> persetujuan PA (scope bimbingan, verifikasi ulang, lock) -> tolak promosikan waitlist.
- Nilai: input (transaction, hormati lock, hanya kelas sendiri) -> kunci -> remedial D/E maks 55 -> buka hanya admin.
- Sidang: penguji -> nilai -> setStatus transaction (jurnal audit + BA lulus).
