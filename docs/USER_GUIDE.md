# Panduan Pengguna (ringkas per peran)

## Mahasiswa
Login → Dashboard (jadwal kuliah hari ini ada di Home mobile) → **KRS**: pilih kelas (cek SKS-maks & tunggakan), ajukan, tunggu PA → **LMS**: materi/tugas/kuis, kumpul tugas, scan QR absensi → **Nilai**: KHS + transkrip cetak → **Keuangan**: buat VA / upload bukti manual, cek status → **Skripsi**: ajukan judul, isi log bimbingan, daftar sidang → **Surat**: ajukan, unduh setelah bernomor → **Notifikasi**: inbox + push.

## Dosen / PA
Setujui KRS bimbingan → kelola materi/tugas → input + kunci nilai → bimbing (setujui log) → uji sidang → EDOM dibaca prodi.

## BAAK / Admin Prodi
Verifikasi PMB (+ berkas) → luluskan → daftar ulang (NIM + tagihan otomatis) → master data → nomor surat → broadcast.

## Keuangan
Generate tagihan massal → verifikasi manual/VA → kwitansi → pantau tunggakan (blokir KRS otomatis).

## Pimpinan
Dashboard pimpinan, PDDikti export, laporan. **Integrasi** (superadmin): isi kredensial + Tes Koneksi.
