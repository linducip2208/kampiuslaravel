# USER_GUIDE (ringkas)
- Login via /login sesuai role. Dashboard menyesuaikan izin.
- Mahasiswa: KRS pengajuan, bayar tagihan (VA/QRIS/manual), kumpul tugas, skripsi, surat, cuti.
- Dosen: KRS persetujuan (jangan pakai route pengajuan), perwalian, materi, nilai (hanya kelas sendiri), pembimbing, nilai sidang.
- Keuangan: tagihan massal, verifikasi bayar, beasiswa, refund (hanya verified & belum refund).
- BAAK/Admin: PMB verifikasi, user, master, kurikulum, jadwal, impor CSV, integrasi.
- Pimpinan: dashboard pimpinan, funnel PMB, laporan, PDDIKTI.
